RepoTower is an offline dependency explorer for Java, Python, C, C++, Go, Rust, C#, JavaScript and TypeScript. Select a file, disconnect it in the simulation, and trace potential impact along real dependency edges.

This first public release includes a compact 2D graph, All/Nearby/Impact views, right-drag node positioning, individual restoration, replayable impact history, and English/Chinese/Japanese UI. New profiles start in English and light mode.

### Downloads

| File                         | Use                                                                |
| ---------------------------- | ------------------------------------------------------------------ |
| `*-windows-x64-portable.zip` | Extract the complete folder and open `RepoTower.exe`.              |
| `*-windows-x64.exe`          | Single download; unpacks into `RepoTower-data` beside the EXE.     |
| `*-macos-arm64.zip`          | Apple Silicon Mac.                                                 |
| `*-macos-x64.zip`            | Intel Mac.                                                         |
| `*-linux-x64.tar.gz`         | Linux desktop, x64.                                                |
| `SHA256SUMS.txt`             | Integrity checks for all binary downloads.                         |
| Source code                  | MIT-licensed source; build dependencies are downloaded separately. |

No language SDK or internet connection is required to use the binaries. Keep the app in a writable folder. Source repositories are read only; disconnecting a node never edits or executes a source file.

Binaries are unsigned and macOS builds are not notarized. See the [distribution notes](https://github.com/cabal312512/RepoTower/blob/v0.5.0/docs/DISTRIBUTION.md) for portable data, platform requirements and checksum verification. Static resolution has [language-specific limitations](https://github.com/cabal312512/RepoTower/blob/v0.5.0/docs/LANGUAGES.md).
