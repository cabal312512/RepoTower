# RepoTower 0.6.0

RepoTower now runs as a native Rust desktop application, with the compact interface and interactive dependency circuit retained.

- Native egui / wgpu window with an in-process Rust analysis engine.
- Windows single EXE runs directly: no Electron, Chromium, WebView2 or application payload extraction.
- All / Nearby / Impact views, attached arrows, right-button node dragging, position resets and persistent cameras.
- Real dependency-wave playback with pause, stepping, scrubbing, replay and cut history.
- Independent cut restoration with shared failures preserved, undo and restore all.
- Built-in JS/TS, Java, Python, C/C++, Go, Rust and C# analysis and examples.
- English, Chinese and Japanese; light/dark appearances and reduced motion. New profiles default to English/light.
- Embedded fonts, grammars and licenses. Runtime use is offline and never modifies inspected source.

## Downloads

Choose the Windows `.exe` to run the application on its own, or the Windows portable ZIP for the same executable with documentation. macOS has Apple Silicon and Intel app archives. Linux has an x64 tar.gz. `SHA256SUMS.txt` and source archives accompany the release.

Application-managed data lives in adjacent `runtime-data`. Windows binaries are unsigned; macOS bundles are ad-hoc signed but not notarized. See [platform requirements](https://github.com/cabal312512/RepoTower/blob/v0.6.0/docs/DISTRIBUTION.md).

The old [Electron 0.5.0 release](https://github.com/cabal312512/RepoTower/releases/tag/v0.5.0) remains available and is not overwritten.
